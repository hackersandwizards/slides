# A slide type for one to three short statements, and a check that catches the wrong type

A content slide of two short bullets (talks `talk-factory-wps` slide 6) leaves the slide empty
around them. Find or build the type that carries one to three short statements, write when to use
it into the engine's guidance, and make `slides-density` fail on a content slide of two or fewer
short bullets, naming the type to use.
